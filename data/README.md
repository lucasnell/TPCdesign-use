# data

Derived files only; nothing here is raw data.
Everything except this README and `.gitignore` is excluded from git and is
regenerated by the scripts below.
Column definitions are in each source folder's README.

| Path | Written by | Contents |
|---|---|---|
| `factorial-test/big-ace-test-01.csv` … `-36.csv` | `01-factorial-test/factorial-cluster.sh` (on BioHPC; copied back) | Paired optimized and equal-spaced fits across the factorial grid, plus one row of true parameters per combination |
| `prior-sensitivity/target-ace-test-01.csv` … `-09.csv` | `02-prior-sensitivity/prior-cluster.sh` (on BioHPC; copied back) | Paired fits under biased and too narrow or wide priors |
| `figure-summaries/Figure_2B_summary.csv` | `03-manuscript-figures/figure-2.R` | Values plotted in Figure 2B |
| `figure-summaries/Figure_3_summary.csv` | `03-manuscript-figures/figures-3-S1.R` | Values plotted in Figure 3 |
| `figure-summaries/Figure_S1A_summary.csv`, `Figure_S1B_summary.csv` | `03-manuscript-figures/figures-3-S1.R` | Values plotted in Figure S1 |
| `figure-2-cache/{shared,varying}/run_001.rds` … `run_200.rds` | `03-manuscript-figures/figure-2.R` | One Figure 2A re-simulation each: a list of `fits`, `designs`, and `observations` |
| `figure-2-cache/{shared,varying}/inputs.rds` | `03-manuscript-figures/figure-2.R` | Cache signature (input rows, design function, package versions); the script stops if it no longer matches |

In `figure-2-cache/`, `shared/` runs all use one prior offset (for the example
curves) and `varying/` runs use each row's own offsets (for the boxplots).
Delete a cache folder to force those runs to be redone.

Run order: the two cluster jobs first, then the two `03-manuscript-figures/`
scripts.
